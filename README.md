# Ashlar Lawyer Hub — Admin

React admin panel for reviewing and approving lawyer onboarding.

## Setup

```bash
cd admin
npm install
npm run dev
```

Open `http://localhost:5173`

Login: `admin@ashlarlaw.com` / `admin123`

The Vite dev server proxies `/api` and `/uploads` to the backend at `http://localhost:3000`.

## Features

- Dashboard stats (pending / approved / rejected)
- Search and filter lawyers
- Review full profile, documents, availability, fees
- Approve, reject, or mark pending
